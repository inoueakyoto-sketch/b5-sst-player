# B5 SST Player v0.10.7


## v0.10.7 の変更
- **文字とボタンの衝突防止**を全体に追加。長い文・ルビ付き文でもボタンの高さが自動で伸び、本文を覆わない。
- 選択肢の番号と本文を2列配置に変更し、既読の「みた」表示も本文に重ならない通常フローへ移動。
- 「ポイント」「言い方の例」「振り返り」「エンディング」などの主要本文サイズを引き上げ、画面に対して小さすぎる表示を改善。
- 高さ520px以下の横画面では、文字を8〜10pxまで縮める旧方針を廃止。**読める文字サイズを維持し、必要ならパネル内をスクロール**する。
- ナレーション本文は明るい水色、登場人物のセリフ本文は白、心の声は薄紫に固定。話者ラベルだけでなく**本文の文字色そのもの**を区別。
- 上部の進捗表示とSSTコーチパネルの間隔を広げ、進捗UIがパネル内容へ被る問題を抑止。
- `.sststory` の形式は変更していないため、v0.10.6で読み込めるStoryはそのまま利用可能。


## v0.10.6 の変更
- **1画面1タスク、最大2タスク**を基本ルールに変更。情報を一度に積み上げず、短いページ送りで順に見せる。
- SST開始前の「ねらい」を2ページ化。①学ぶこと＋テーマ、②なぜ大切＋将来の使用場面。
- 振り返りを2ページ化。①自分の目的と相手に起きたこと、②学習ポイント。
- モデリングを分割。①実際のやりとり、②ポイントは最大2個ずつ、③言い方の例は最大2個。
- 物語終了後の確認編導入から5項目一覧を外し、まず1つの説明だけを表示。
- エンディングの5スキル一覧を2つずつページ送りにし、その後「将来につながる力」「現実ミッション」を別ページ化。
- 選択肢は「1つの課題に対する回答候補」なので、5択などは同一画面のまま維持。教材構造・正誤・学習内容は変更していない。
- 選択後の反応画面では、重複する「選んだ内容」や補助説明を減らし、まず相手の反応を見ることに集中できるようにした。


## v0.10.5 の変更
- 物語モードで、ナレーション・登場人物のセリフ・心の声を色と話者ラベルで明確に分離。
- `[[漢字|かな]]` のルビ表示を維持し、漢字＋ルビ中心のストーリー本文に対応。
- つなぎ場面の `lines` が speaker/text/kind を持つ形式に対応し、ナレーション文中へセリフを埋め込まず別表示できるよう拡張。
- `story.meta.futureSummary` をエンディングに表示し、話ごとの将来スキルに対応。
- 旧ストーリーの文字列形式transitionも引き続き読み込み可能。

## v0.10.4 の変更
- ライブラリ画面とプレイ中画面に、Playerバージョンを常時確認できる表示を追加。プレイ中は読み込んだStoryバージョンも併記。
- SST開始前画面を「これから学ぶこと」最優先の構成へ刷新。SSTのねらい本文を最も大きく表示し、テーマ・重要性・将来の活用先を補助情報として整理。
- 横向き低高さ端末でも、学習目標本文が従来より大きく読めるよう専用レスポンシブ調整を追加。
- QAで見つかった第1話固定表示を修正し、上部の話数・開始画面の話数をstoryIdから表示。第1話専用の経路表示は他話では非表示にし、振り返り見出しも汎用化。

## v0.10.2 の変更
- SST開始前の「SSTのねらい」を約2段階大きくし、重要情報として見やすく表示。
- 状況確認・観察・振り返り・モデリングなどのコーチ説明パネルを一回り大きく。
- 状況確認画面の「つぎへ」ボタンに十分な上余白を追加し、直前のフィードバック枠との重なりを解消。
- 選択後の「相手の反応」は物語画面下部のセリフ領域に表示。
- 相手の反応とSSTコーチの解説を同時表示せず、反応を見た後に解説・観察画面へ進む流れに分離。
- 立て直し後の相手の反応も同じ下部セリフ表示へ統一。
- SST内容・選択肢・ストーリー内容・`.sststory` 形式は変更していません。

## v0.10.1 の変更
- ストーリー実行中の上部に「← いちらんにもどる」を常時表示。
- 押すと確認ダイアログを出し、確認後にストーリー一覧へ戻る。
- 現在位置は保存されないことを確認画面に明示。

## 基本構成
- Player本体とストーリーを分離。
- Google Drive等からダウンロードした `.sststory` を「ストーリーをついか」から読み込み。
- 読み込み時にB5 SSTガードレールを自動検査。
- 読み込み済みパックはIndexedDBへ保存。
- パックからHTML/JS/SVG等の実行可能コンテンツを拒否。
