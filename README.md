# B5 SST Player v0.10.4


## v0.10.4 の変更
- ライブラリ画面とプレイ中画面に、Playerバージョンを常時確認できる表示を追加。プレイ中は読み込んだStoryバージョンも併記。
- SST開始前画面を「これから学ぶこと」最優先の構成へ刷新。SSTのねらい本文を最も大きく表示し、テーマ・重要性・将来の活用先を補助情報として整理。
- 横向き低高さ端末でも、学習目標本文が従来より大きく読めるよう専用レスポンシブ調整を追加。
- QAで見つかった第1話固定表示を修正し、上部の話数・開始画面の話数をstoryIdから表示。第1話専用の経路表示は他話では非表示にし、振り返り見出しも汎用化。

## v0.10.2 の変更
- SST開始前の「SSTのねらい」を約2段階大きくし、重要情報として見やすく表示。
- 状況確認・観察・振り返り・モデリングなどのコーチ説明パネルを一回り大きく。
- 状況確認画面の「つぎへ」ボタンに十分な上余白を追加し、直前のフィードバック枠との重なりを解消。
- 選択後の「相手の反応」は物語画面下部のセリフ領域に表示。
- 相手の反応とSSTコーチの解説を同時表示せず、反応を見た後に解説・観察画面へ進む流れに分離。
- 立て直し後の相手の反応も同じ下部セリフ表示へ統一。
- SST内容・選択肢・ストーリー内容・`.sststory` 形式は変更していません。

## v0.10.1 の変更
- ストーリー実行中の上部に「← いちらんにもどる」を常時表示。
- 押すと確認ダイアログを出し、確認後にストーリー一覧へ戻る。
- 現在位置は保存されないことを確認画面に明示。

## 基本構成
- Player本体とストーリーを分離。
- Google Drive等からダウンロードした `.sststory` を「ストーリーをついか」から読み込み。
- 読み込み時にB5 SSTガードレールを自動検査。
- 読み込み済みパックはIndexedDBへ保存。
- パックからHTML/JS/SVG等の実行可能コンテンツを拒否。
